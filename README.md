# Маркетинг Медиа

Сравнительный анализ конкурентов (продукт, контент, соцсети, тренды) и генератор промоплана для сериалов, телепрограмм, фильмов и медиабрендов.

Собрано по [PRD marketing media.md](PRD%20marketing%20media.md).

**Демо:** см. GitHub Pages этого репозитория (`index.html`).

> Заметка: AI-функции (кнопки «✦ …») и экспорт файлов используют возможности среды Claude Artifacts и доступны только при открытии страницы как Claude-артефакта. На GitHub Pages работают реестр конкурентов, таблицы, автоформулы ER/охвата, сравнительные графики, быстрый шаблон промоплана и локальное сохранение данных в браузере — эти AI-кнопки будут скрыты/неактивны.
